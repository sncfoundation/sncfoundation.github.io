What it is

SheetOS is Talos for spreadsheets: a declarative, API-only node OS whose single job is to bootstrap and run Sheeternetes. Nodes are configured by a machineconfig, never by hand; sheetstrap brings a control-plane or worker node up, and the OS is distributable across many sheets that self-assemble into a cluster.

Features

📜

Declarative machineconfig

No shell, no hand-edits — everything is a config, like Talos.

🥾

One-command bootstrap

sheetstrap gen-config / bootstrap / join.

🌌

Distributed

Many sheets, one cluster. Eventually consistent, honestly so.

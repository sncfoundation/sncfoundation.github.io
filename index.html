What is Sheet-Native Computing?

A discipline in which the substrate is not a cluster but a workbook, state is not a database but a range, and the reconciliation loop runs on a trigger every minute, forever, because the spreadsheet is eternal. Five principles define it — read them on the Foundation charter.

What it is

Sheetlium is the L3/service layer. A shared Docker network gives every pod connectivity, and each Deployment name is registered as a DNS alias — a round-robin Service. So curl http://web reaches the web Deployment's replicas, load-balanced by embedded DNS. Services, without the CRDs.

Features

🕸️

Services by name

Each Deployment name is a round-robin DNS Service — no manifests, no CRDs.

⚖️

Built-in load balancing

Docker's embedded DNS spreads traffic across replicas automatically.

🔎
